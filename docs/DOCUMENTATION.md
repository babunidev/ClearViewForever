# Documentation standard

- README.md: behavior, installation, supported Forever build, commands and verification.
- CONCEPT.md: original creative goal and stable design principles.
- ROADMAP.md: unresolved and future development, not claims of completed work.
- CHANGELOG.md: released versions separated from unreleased development.
- docs/: detailed verified research, architecture and testing as necessary.

Keep statements evidence-based; separate proposed, implemented, automatically tested, in-game tested and released. Respect authorship: Babuni directs the concept; OpenAI contributes implementation and research. Avoid implying a tag or repository commit is a public release.
